# Bike Rental Shop SQL Case Study

## 📌 Project Overview

This project analyzes the operations of a bike rental shop using SQL. The objective is to answer real-world business questions related to inventory management, customer behavior, rental revenue, and memberships.

The case study is based on a practical business scenario where the shop owner needs data-driven insights to support business decisions.

---

## 🎯 Business Objectives

The project answers the following business questions:

1. Count bikes by category.
2. Analyze customer memberships.
3. Calculate discounted rental prices.
4. Compare available and rented bikes.
5. Generate monthly and yearly rental revenue reports.
6. Analyze membership revenue by type and time period.
7. Create subtotals and grand totals for membership sales.
8. Segment customers based on rental activity.

---

## 🗄 Database Schema

The database consists of five tables:

| Table           | Description              |
| --------------- | ------------------------ |
| Customer        | Customer information     |
| Bike            | Bike details and pricing |
| Rental          | Rental transactions      |
| Membership Type | Membership plans         |
| Membership      | Customer memberships     |
